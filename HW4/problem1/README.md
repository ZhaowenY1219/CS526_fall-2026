problem1(a)
-------------------------------------------------------------------------------------------------------------------------------
1. What is the sequence of nodes (characters) generated by preorder tree traversal
   Answer: A-B-E-H-F-I-C-D-G

   The rule for pre-order traversal is: root - children from left to right
   
   
2. What is the sequence of nodes (characters) generated by breadth-first tree traversal

   Answer: A-B-C-D-E-F-G-H-I

   breadth-first tree traversal rule is : Iterate through the tree hierarchically, from top to bottom, and from left to right on each level.
   
   
3. What is the sequence of nodes (characters) generated by post tree traversal

   Answer: H-E-I-F-B-C-G-D-A

   The rule for postorder traversal is: First, traverse all subtrees of the current node, and then visit the current node itself.

------------------------------------------------------------------------------------------------------------------------------
1. What is the sequence of nodes (characters) generated by in-order tree traversal

   Answer: D-G-B-E-A-C-H-F-I

   The in-order traversal rule is left subtree - root node - right subtree.
